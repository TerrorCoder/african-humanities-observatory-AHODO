# African Humanities Open Data Observatory — Discovery Dataset v0.3

Released 2026-09-22. This public dataset contains **11,650** item-level discovery records across **12** item source families and **12** item-holding institutions. It describes African humanities and adjacent resources with source, rights and provenance context. It is not the underlying works and is not a representative sample.

The complete set has **10,398** core humanities, **1,127** humanities-adjacent and **125** broader social-science records. A core-only and a humanities-plus-adjacent subset are supplied. **10,850** records are held by African institutions. Holding country differs from subject geography; the latter is not established for **11,496** items.

Acquisition categories are **{'oai_pmh': 10497, 'controlled_http': 241, 'official_api': 800, 'firecrawl': 112}**. The public source manifest lists institutions, collections, resource rights and evidence URLs. Rights are resource-specific. **10,738** items have no established metadata licence, and no blanket AI-training clearance is asserted. Community governance `not_provided` does not imply consent.

JSONL preserves repeatable/nested fields; CSV is a convenience index. The files are a public projection of the audited release: audited discovery and rights values remain unchanged, while exact acquisition requests, private raw paths and internal workflow fields are omitted. See [projection integrity](../dataset/v0.3/projection-integrity.json), [the dictionary](DATA_DICTIONARY.md), [rights](RIGHTS_AND_PROVENANCE.md), [limitations](KNOWN_LIMITATIONS.md) and [source manifest](SOURCE_MANIFEST.md).
