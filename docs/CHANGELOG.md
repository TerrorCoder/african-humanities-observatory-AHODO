# v0.3 changelog

The audited v0.3 release contains **11,650** items, including **10,398** core humanities items. It expands beyond v0.2 through reviewed institutional APIs, OAI-PMH and bounded catalogue acquisition. Expansion reflects available authoritative interfaces, not improved representativeness. Rights, geography, language and provenance uncertainty remain explicit.

This public distribution projects the audited v0.3 exports into a smaller public record format. Stable IDs, titles, contributors, dates, languages, subject geography, holding institution, scope, resource-rights and community-governance values are retained. Exact acquisition requests, raw-capture paths and internal workflow fields are omitted; the [projection-integrity manifest](../dataset/v0.3/projection-integrity.json) gives original/public file hashes and counts. Dataset statistics are byte-identical to the audited release.
