# Methodology

AHODO reviews an authoritative source and its access and rights conditions, acquires only an approved resource scope, retains original source metadata, normalizes cross-collection discovery fields, classifies scope, maps rights to individual resource types, records provenance, checks duplicates and validates the release.

Acquisition routes for v0.3 include institutional APIs, OAI-PMH, structured metadata, and controlled web acquisition. Public records identify the source family, institution, authoritative item identifier, item URL where established, acquisition category, retrieval time and resource-rights assessment. The public source manifest provides source and rights-evidence URLs. This methodology describes the meaning of the released artifact; it does not reproduce historical requests or guarantee the continued availability of external sources.

Scope classification comes from source metadata and documented rules. It is not a human reading of each work. Language is source-stated, and subject country is not inferred from holding country, language or contributor. Duplicate work identifiers can refer to distinct repository objects or editions; possible groups are not automatically merged. The current public files are a projection of the audited release: [the projection note](../dataset/v0.3/projection-integrity.json) records original and public export hashes.
